# ⚡ Quick Start - Comece em 2 minutos!

## 1️⃣ Instale
```bash
npm install
```

## 2️⃣ Rode
```bash
npm run dev
```

## 3️⃣ Abra
Acesse: **http://localhost:3000**

## 🎉 Pronto!

Seu site está rodando localmente!

---

## 🔧 Próximos Passos Recomendados

1. **Atualizar WhatsApp**
   - Arquivos: Hero.tsx, CTA.tsx, FloatingWhatsApp.tsx
   - Procure: `5500000000000`
   - Substitua pelo seu número com código de país

2. **Trocar Imagens**
   - Hero: fotos do estúdio/aplicação
   - About: foto profissional da Camila
   - Localize `https://images.unsplash.com` nos componentes

3. **Deploy**
   - Use Vercel, Netlify ou seu servidor
   - Veja README.md para mais detalhes
